Every graphic on this page is generated inside this repository, not pulled
from a third-party stats-card service. The portrait above is a real photo
pushed through a character ramp by `scripts/make_portrait.py`. The graphics
below are drawn straight from the GitHub GraphQL API by a scheduled
Action, once a day, committing only what changed.

They animate once, on load, using SMIL inside the SVG &mdash; GitHub strips
`<script>` from README-embedded images, but SMIL survives. Nothing on this
page makes a request to anyone else's server, so nothing here can
rate-limit or go dark.
